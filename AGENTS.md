# Agents — portfolio

## Stack

Astro 7 static site. Blog via Content Collections + lokale Markdown/MDX in `src/content/blog/`. Geen Directus of ander CMS.

## Dev-server

```sh
npm run dev
```

Voor background mode (Astro CLI):

```sh
npx astro dev --background
```

Beheer met `astro dev stop`, `astro dev status`, `astro dev logs`.
